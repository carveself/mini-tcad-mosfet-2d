# 默认结果索引

所有数据为程序计算，不含实测器件数据。8 张 PNG 对应：二维电势、中心线势垒、短沟道扫描、四端电容/响应、设计空间、同 EOT 对照、尺度长度和验证。

10 个 CSV 保存势垒剖面、电容、长度/设计扫描、长度搜索、介质对照、空间衰减、制造解、独立网格比较及长沟道极限。NPZ 保存二维图的 x/z 单元边界及两档漏压电势；单位 nm、V。

`summary.json` 包含基准条件与提取值；`validation.json` 包含误差和守恒。电容 CSV 的行列序都是 source / drain / bottom_gate / top_gate，单位 F/m 宽度。两栅短接等效电容取右下 2×2 子块元素之和。

阈值与 DIBL 是中心线 0.20 eV 势垒判据的静电定义，漏压为 0.05/0.70 V；不是电流测量。极短厚硅情况下的负栅压判据可能超出实际全耗尽适用范围。接触电势 0.9 V 是给定边界参数。

结果的参数、范围和误差说明见主 README 与 docs/VALIDATION.md。改变模型或网格后请保留自己的条件记录；不要直接沿用默认报告数字。
