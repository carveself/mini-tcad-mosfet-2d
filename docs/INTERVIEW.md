# 项目口述与追问练习

这份材料帮助你练习真实复现后的表达，不代表任何院校认可或保证加分。只有理解、重写和验证过的部分，才按自己的实际贡献讲述。参考实现与工具辅助如实说明。

## 三分钟项目练习结构

**约 30 秒：问题。** 从一维静电/输运走向二维，研究漏极如何影响源端势垒，薄硅膜为什么有利于栅控，以及满足特定 DIBL 目标需要多长沟道。采用固定电荷全耗尽模型，专注静电几何。

**约 50 秒：方法。** 画出介质/硅/介质域和边界。说明有限体积的共享面通量、介电常数串联电阻、稀疏线性求解，以及为什么固定电荷下能精确叠加四端响应。阈值必须说明是中心线 0.20 eV 势垒判据。

**约 50 秒：验证。** 讲制造解、独立三角形 FEM、网格和长沟道极限。必须同时说中心势垒与全域误差：最细网格势垒差约 0.1107 meV，全域最大电势差仍 27.87 mV，接触端点不能忽略。说明守恒不是独立正确性证明。

**约 30 秒：一个有价值的发现。** 任选一个讲深：同 EOT 仍有不同二维边缘场；抛物尺度长度低估约 13%；或 50 mV/V 约束下 10 nm 硅膜对应约 35.6 nm 沟道。

**约 20 秒：个人贡献和边界。** 加入自己确实完成的一次修改、一次失败与修复证据。说明未求移动载流子与输运，不能把结果包装成实测漏电或完整 MOSFET 性能。

## 英文简介

I reproduced a two-dimensional electrostatic model of a depleted double-gate silicon MOSFET. The model solves Poisson's equation with dielectric interfaces and mixed boundary conditions. I compared conservative finite volumes with an independently assembled triangular finite-element solver, checked mesh convergence and charge conservation, and extracted a centerline barrier-based DIBL metric. I also studied scale length and same-EOT fringing, then searched for a channel length meeting a specified electrostatic target. The main limitation is the fixed-charge approximation: mobile-carrier screening and drain current are not solved.

## 追问与回答线索

| 问题 | 回答要点 |
| --- | --- |
| 上个项目有输运，这次为什么只有静电？ | 新难点是二维几何、介质界面、混合边界和跨方法验证；选择更简单的物理模型便于隔离几何影响 |
| 为什么用谐均而不是算术平均介电常数？ | 法向通量必须穿过两段介质，中心到面距离参与串联电阻；推导面系数 |
| 漏端电势升高为什么电子势垒降低？ | 电子能量随 -q psi 变化；沟道最低 psi 升高，最大 Ec 相对源端降低 |
| 你报告的阈值是什么？ | B=0.20 eV 的中心线栅压，不是实测恒流或强反型阈值；需报告漏压和接触条件 |
| 只看中心线是否足够算电流？ | 不够；实际输运路径与载流子权重需要连续性方程和适当输运模型 |
| 低残差、守恒都很好，为何还要验证？ | 可能准确求解了错误装配；保守性质部分来自结构，需要已知解和独立离散交叉核查 |
| 势垒差很小，为何全域最大电势差较大？ | 观察区域和量不同；端点混合边界有奇异梯度，两种端点处理不同；不能选择性报告误差 |
| FEM 独立在哪里？ | 从三角形形函数梯度装配刚度，没有复用 FVM 面通量；仍共享物理和边界假设 |
| 同 EOT 为什么 DIBL 不同？ | 一维平面电容相同，实际厚度改变二维边缘场；说明固定的其他条件 |
| 尺度长度从哪里来？ | 分离变量、硅余弦与氧化层正弦，接口 D 连续得到正切方程；小角近似才得到平方根公式 |
| 为什么 C 的行和是零？ | 全部端电势共同平移不改变场和电荷；电势规范自由度 |
| 为什么长沟道短接栅电容不随面积增长？ | 固定电荷没有反型载流子响应，内部近似随栅平移，只剩端部小信号贡献 |
| 35.563 nm 是真实工艺极限吗？ | 不是；指定静电模型和目标的数值边界，网格检查约 0.016 nm 差异不涵盖物理模型误差 |
| 为什么有负的阈值结果？ | 极短厚硅模型中漏控制很强，但负栅压可能违反全耗尽假设；保留并标明外推，不当作有效器件预测 |
