# 验证记录

环境：Python 3.12、NumPy 2.3.5、SciPy 1.18.1、Matplotlib 3.11.2。

```bash
python run_all.py
python -m unittest discover -s tests -v
```

默认基准已实际运行；14 项测试通过。测试覆盖高斯平衡、电容互易与正半定性、规范平移、电荷数值微分、上下与左右对称、栅漏势垒趋势、长度/硅厚趋势、独立 FEM、制造解误差阶、长沟道解析极限、尺度长度、零源项最大值原理、无效参数与括根失败。

## 独立离散的完整误差记录

默认器件 L=30 nm、Vg=0.5 V、Vd=0.7 V：

| h / nm | FVM 势垒 / eV | FEM 势垒 / eV | 全域 RMS 电势差 / mV | 全域最大电势差 / mV |
| --- | ---: | ---: | ---: | ---: |
| 1.0 | 0.271993 | 0.269850 | 9.028 | 92.099 |
| 0.5 | 0.271523 | 0.270751 | 3.932 | 65.892 |
| 0.25 | 0.271333 | 0.271043 | 1.643 | 43.466 |
| 0.125 | 0.271256 | 0.271145 | 0.672 | 27.875 |

最细网格势垒差约 0.1107 meV。去除距左右端各 3 nm 的区域后，最细网格的最大电势差约 0.767 mV。只用中心势垒误差不能代表整个域的误差；接触终点的混合边界和不同端点表示是局部差异的重要来源。这里没有把某个网格解当作真实解，也没有用差异给出严格误差上界。

FVM 与 FEM 是两套独立装配，但共享几何、物理与边界假设，且 FEM 插值到 FVM 中心后比较。它们不能检验模型缺少移动载流子、量子效应或真实接触的误差。

## 结果与可复现性

默认 51 个长度扫描点、66 个 L/tsi 设计空间点、18 个同 EOT 介质对照点；每个 DIBL 都来自两档漏压各自的势垒判据求根。约束长度对三种硅膜、两级网格分别搜索。所有数据由确定性求解产生，无随机数、无实验室数据。

程序输出只依赖数值计算，PNG 的二进制可能随字体和库版本不同。JSON 的残差末位受线性代数实现影响；请比较合理容差下的物理量，不以图片文件哈希判断科学结果是否相同。

## 数据位置

- `figures/summary.json`：基准参数、DIBL、端电荷、搜索结果、尺度长度。
- `figures/validation.json`：制造解、参考比较、残差和守恒。
- `figures/independent_mesh.csv`：完整四网格误差指标。
- `figures/manufactured_convergence.csv`、`long_channel.csv`：已知解检查。
- `figures/design_search.csv`、`design_sweep.csv`、`length_sweep.csv`：几何目标和趋势。
- `figures/dielectric_sweep.csv`：同 EOT 对照及双栅短接电容。
- `figures/screening.csv`：空间响应和指数拟合。
- `figures/capacitance_F_per_m.csv`：S/D/Gb/Gt 顺序的矩阵。
- `figures/potential_maps.npz`、`barrier_profiles.csv`：势垒与二维图的原始数组。

说明：以上路径相对于仓库根目录。`stages.py` 的单阶段输出由指定目录保存，不自动改写本记录。改变参数后应更新自己的验证记录，不能沿用基准的表格数字。
