# 第四阶段：从二维求解到一个可解释的设计结论

先按主 README 运行基准和 14 项测试，保存环境版本。保留参考分支，自己重写和试验的内容放在新分支；不要把仅运行参考程序描述为独立实现。

## 1. 画出域与边界

```bash
python src/stages.py baseline --output reproduction/01-baseline
```

手画下介质/硅/上介质截面，标出四个端子和两个绝缘侧壁段。说明正漏压为什么使漏端电势升高、导带能量降低。解释源端 0.9 V 是给定边界参数，不是本程序算出的源区内建势。

检查：上下栅相同时电势关于 z=0 对称；Vd=0 时源漏方向对称；全域 rho 只有硅单元带负电。阅读 NPZ 中的边界坐标和二维电势数组，不只看 PNG。

## 2. 重写共享面通量

从积分泊松方程推导每个单元的对角与邻接项。先在均匀介质中重写，再加入两种介质。重点推导 dL/kL+dR/kR 的串联电阻，验证同一面从两侧看通量互为相反数。

动手：在自己的分支临时换成算术介电平均，与原模型的制造解误差比较，说明差异来自哪里。不要把错误版本生成的结果混入基准。

## 3. 建立可信度链条

```bash
python src/stages.py verify --output reproduction/02-verification
```

先复现光滑制造解的近二阶收敛；再读 FEM 形函数装配，解释它没有复用 FVM 面系数。比较 1/0.5/0.25/0.125 nm 四级网格，报告势垒差和全域电势差。

需要讲清楚：为什么势垒只差 0.1107 meV，而全域最大电势仍差 27.87 mV？答案应包括观察量位置、混合边界端点、网格光滑性与两种端点表示。制造解二阶并不自动保证真实器件问题也全域二阶。

独立实验：把源漏接触端点周围的误差画大，改变接触排除区宽度，检查报告指标对区域选择的敏感性。

## 4. 解释四端电容

按端序 S/D/Gb/Gt 手算双栅短接等效电容应取哪些矩阵元素。用小电势增量数值微分端电荷，检查电容互易、行列和、正半定性与高斯平衡。再将所有端同时加 0.3 V，检查电势只平移、端电荷不变。

追问：这里的总栅电容为什么在长沟道时趋于常量？联系固定电荷、内部随栅平移和端部场，不要把它当强反型器件面积电容。

## 5. 从漏压响应提取尺度长度

```bash
python src/stages.py screening --output reproduction/03-screening
```

用分离变量推导硅余弦、介质正弦及界面条件，得到分层模态方程。把两个正切作小角展开，得到近似尺度长度。解释 6.30837、6.30503、5.47723 nm 分别来自哪里。

动手：把拟合区间从 15-45 nm 改为 3-12 nm、30-60 nm，量化拟合变化；预测高阶模态和另一端边界何时会影响结果。增加氧化层厚度后，小角近似是否更可靠？先预测再运行。

## 6. 同 EOT 的对照实验

```bash
python src/stages.py dielectric --output reproduction/04-dielectric
```

确认三组 tox/k 对应相同 EOT。固定 L、tsi、接触和判据，比较 DIBL。说明 EOT 约束的是一维平面单位面积电容，二维边缘场仍看得到实际几何。

可做自己的扩展：固定物理厚度改变 k，与固定 EOT 改变物理厚度比较。两组实验回答不同问题，不能混为同一个参数因果。

## 7. 做一个带条件的设计搜索

```bash
python src/stages.py design --output reproduction/05-design
```

复现 50 mV/V 目标，tsi=10 nm 时粗细网格长度约为 35.547/35.563 nm。写出目标、变量、固定参数、可行区间与停止容差。按约 35.6 nm 报告，不把求根器的多位小数当真实制造精度。

动手：将目标改为 30 或 80 mV/V；把势垒判据改为 0.15/0.25 eV；改变漏压组合。若根未被括住，应报告失败并有理由地调整搜索区间，不直接放宽到模型不适用范围。

## 8. 形成自己的研究记录

选一个扩展深入完成，形成一页“问题—预测—实验—验证—局限”日志。保留一次失败及修复证据。可选：界面固定电荷导致上下不对称；对独立上下栅提取耦合；接触几何改变；固定电荷与平衡移动电荷的适用性比较。

只有确实实现并验证后，才把扩展写进自己的贡献。参考代码、工具辅助和实测数据来源应如实说明。
