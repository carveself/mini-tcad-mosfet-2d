# 方程、几何与可验证的近似

## 1. 域与边界

x 从源端 0 到漏端 L；z 跨越下介质、硅、上介质。硅范围为 -tsi/2 到 tsi/2，两个介质各厚 tox。没有显式源漏延伸区；硅左右端面就是理想定电势接触。

默认源、漏电势为 0.9 V、0.9 V+Vd，上、下栅分别为 Vg-Vfb、Vgb-Vfb。Vfb=0。0.9 V 是预设的有效接触偏置，不使用重掺杂玻尔兹曼公式解释该值。若传入非零 Vs，各端输入均为相同参考下的绝对外加电势；只有默认 Vs=0 时，vd 也等于 Vds。

介质左右侧壁为零法向通量，顶底边界是栅极。硅/介质界面电势连续、法向电位移连续，无界面固定电荷。端面接触与绝缘侧壁的交接点形成混合边界；在独立 FEM 中界面端点节点归接触，FVM 则按硅边界面施加接触。端点附近的梯度奇异性会限制器件问题的整体收敛速率。

## 2. 方程与单位

```math
-\nabla\cdot(\varepsilon\nabla\psi)=\rho,\qquad
\rho_{Si}=-qN_A,\quad \rho_{ox}=0.
```

这是 Fully depleted approximation（全耗尽近似）：固定负电荷代表完全电离受主，移动载流子不参与泊松屏蔽。它适合研究选定的亚阈值静电趋势，不能计算强反型电流。给定偏压不自动保证全耗尽近似成立，尤其要检查负栅压、极短沟道以及源漏端附近。

程序坐标为 nm，介电常数存相对值 k。因此离散前写成：

```math
-\nabla_{nm}\cdot(k\nabla_{nm}\psi)=\rho\,10^{-18}/\varepsilon_0.
```

NA 从 cm⁻³ 乘 1e6 转为 m⁻³。二维体积分乘 1e-18 转为 m²，得到单位宽度的固定电荷 C/m。没有温度输入，因为本模型没有统计分布、迁移率或载流子输运。

## 3. 有限体积

在每个矩形单元积分方程。面通量以两侧中心到界面的介质串联电阻求值：

```math
g_f=\frac{A_f}{d_L/k_L+d_R/k_R},\qquad
\sum_f g_f(\psi_P-\psi_N)=s_P.
```

Af 为二维面的长度，dL/dR 是中心到面的距离。边界定电势同样使用半单元距离。这样法向 D 的连续性由共享面通量保证，不能把不等间距和不同介质简单做算术平均。

装配出的 A 对称正定；顶底 Dirichlet 边界消除了常数零空间。用稀疏 LU 一次分解，再分别解固定电荷和四端单位电势响应：

```math
\psi=\psi_\rho+H\mathbf V.
```

这里的仿射叠加源于线性固定电荷模型，是精确求解同一离散系统，不是机器学习拟合或额外近似。加入移动电荷后就不能沿用这种偏压无关响应矩阵。

## 4. 独立三角形 FEM

参考实现从三角形顶点的线性形函数梯度装配：

```math
K_{ij}^{(T)}=k_T A_T\nabla N_i\cdot\nabla N_j,
\qquad f_i^{(T)}=\rho_T10^{-18}A_T/(3\varepsilon_0).
```

网格在介质界面处对齐；每个矩形按交替方向拆成两个三角形。Dirichlet 节点消元，绝缘侧壁为自然边界。FEM 没有复用 FVM 面系数、矩阵或势垒剖面作为解，仅共享几何参数、物理常数、层分割和边界约定。

两套模型的物理假设相同，因此一致性只检查离散与实现，不等于与实验一致。比较时 FEM 在 FVM 中心处双线性插值，误差包含参考插值误差；报告全域最大、全域 RMS、接触排除区最大值，避免只报告好看的一个指标。

## 5. 势垒判据

两条紧邻 z=0 的硅中心行对称插值到中心线，并添加已知源漏接触值。设最大电子能量势垒相对源端为：

```math
B=\psi_S-\min_x\psi(x,0)\quad\mathrm{eV}.
```

利用最低点及两个邻点作局部抛物线，只接受开口向上、极小值落在邻域内的修正。没有把接触电势的纵向剖面扩展成二维载流子密度，也没有搜索所有可能输运路径。这里明确使用中心线指标；真实电子可优先通过其他路径，需要输运模型才能决定电流权重。

Vth,B 用标量求根满足 B=0.20 eV，默认栅压括区 [-1,1.3] V；如果没有括住根会报错，不伪造阈值。DIBL 按 Vd=0.05/0.70 V 的两次势垒判据电压差定义。判据、接触值、漏压、几何都必须随结果报告。改变势垒判据可能改变 DIBL，因为势垒位置也随偏压移动。

## 6. 电荷与电容

从介质指向金属的面通量积分，端电荷为：

```math
Q_t=\varepsilon_0\sum_{f\in t}g_f(V_t-\psi_{P(f)})\quad\mathrm{C/m},
\qquad C_{ts}=\partial Q_t/\partial V_s.
```

端序为 source、drain、bottom_gate、top_gate。对角为正、非对角为非正，C 应互易对称、行列和为零，并半正定；零特征值对应所有端共同平移的规范自由度。两个栅短接时的等效栅电容为 C 的右下 2×2 子块元素总和，不能只取 Cgt,gt。

固定电荷加四端电荷和应为零。这是保守离散的重要约束，但与电容互易性一样，部分来自装配结构；它们不能替代制造解、独立离散和网格检验。

本模型没有随栅压增长的反型电荷。长沟道的两个栅同时移动时，内部电势也几乎同幅移动，那里固定电荷不变；小信号栅电荷变化主要来自端部，所以总短接栅电容不会像强反型器件的 CoxWL 那样随 L 线性增长。

## 7. 分层尺度长度

考虑远离源漏、两栅电势扰动为零的拉普拉斯扰动。取横向衰减 exp(-x/lambda)，硅中对称基模 cos(z/lambda)，介质中满足金属边界零值的正弦函数。由界面势与 D 连续得到：

```math
\tan\left(\frac{t_{Si}}{2\lambda}\right)
\tan\left(\frac{t_{ox}}{\lambda}\right)=\frac{k_{ox}}{k_{Si}}.
```

选择两个正切均处第一象限的最小波数根，即最大衰减长度的对称基模。若两个角都足够小，得到常用近似：

```math
\lambda_{para}\simeq\sqrt{\frac{k_{Si}t_{Si}t_{ox}}{2k_{ox}}}.
```

基准几何并不充分满足小角条件，所以近似低估约 13.13%。用 L=120 nm 的单位漏压中心线响应，在距漏端 15-45 nm 拟合 ln(response) 的斜率；拟合得到 6.30837 nm，模态方程为 6.30503 nm。拟合区间避开近漏端高阶模态与远源端反射/极小信号。不是所有响应区域都呈单指数。

## 8. 两个解析/精确检查

长沟道：对称栅、固定硅电荷时，硅内电势关于 z 为抛物线，介质内为直线。`vertical_exact` 给出分段解；L=300 nm 中部与其比较。

制造解：令 r(z)=积分 dz/k，T 为整个层堆栈的 r 总量，t=r/T，规定 psi=cos(2pi*x/L)*t*(1-t)。这样跨介质界面的电势和 D 连续，左右侧壁的法向导数为零；硅侧面的 Dirichlet 值由精确解给定。反推的源项在每个材料内为：

```math
\rho\,10^{-18}/\varepsilon_0=
\cos(2\pi x/L)\left[k(2\pi/L)^2t(1-t)+\frac{2}{kT^2}\right].
```

这是专门用于数值验证的人工电荷分布，不是默认硅受主分布，也不是器件实验数据。它在混合边界交点处相容，能显示光滑问题的二阶收敛。

## 9. 设计搜索的条件

对 tsi=6/10/16 nm，固定其余条件，搜索 L 在 20-100 nm 范围内使 DIBL=50 mV/V；区间内扫描显示 DIBL 随 L 下降。每个候选长度都重新装配几何并求解；两个网格各搜索一次。停止容差 0.01 nm 只是数值求根设置。结果不能推断电流、功耗、工艺偏差或量子限制下的真实最短器件。
